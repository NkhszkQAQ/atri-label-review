# 亚托莉 · 台词标注

适合 iPad 的简单静态标注页，默认深色，可切换浅色。

- 一次显示一条台词，附剧情阶段、前情介绍和原文。
- 支持多选、备注、上一条、跳转、筛选、导入和导出进度。
- 语料使用 AES-256-GCM 加密。专属链接的解密码仅在浏览器片段中读取，不发送给 GitHub；仓库不包含解密码或明文台词。
- 标注保存在当前浏览器的 IndexedDB 中，不自动同步到 GitHub。请定期导出 JSON 备份，换设备时导入。
- 情绪描述可保留复杂、含混和超出七类的情况，不强制变成单一标签；网页不自动训练模型。

GitHub Pages 从 `main` 分支根目录发布，无需构建或服务器。

本地检查：`node --test tests/logic.test.mjs`。本地预览可使用静态 HTTP 服务。
